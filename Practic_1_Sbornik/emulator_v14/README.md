# Эмулятор командной строки UNIX (Вариант 14)

## 1. Общее описание
Десктопное приложение с графическим интерфейсом (GUI) на базе библиотеки `tkinter`, имитирующее работу командной оболочки UNIX-подобной операционной системы. Эмулятор поддерживает работу с виртуальной файловой системой (VFS) в оперативной памяти (in-memory) на основе ZIP-архивов, лексический разбор команд с учётом кавычек и автоматическое выполнение стартовых сценариев.

## 2. Описание всех функций и настроек

### Аргументы командной строки (CLI)
* `--vfs <путь>` — путь к ZIP-архиву для загрузки структуры виртуальной файловой системы в память (если не указан, создаётся демонстрационная структура каталогов по умолчанию).
* `--prompt <строка>` — пользовательское приглашение ко вводу в окне терминала (по умолчанию `emulator$ `).
* `--script <путь>` — путь к файлу стартового скрипта, команды которого автоматически выполняются при запуске приложения.

### Встроенные команды оболочки
* `ls [путь]` — вывод отсортированного списка файлов и подкаталогов в текущей или указанной директории VFS.
* `cd [путь]` — смена текущей рабочей директории VFS (поддерживаются абсолютные и относительные пути, переход на уровень выше `..`, а также имена каталогов с пробелами в кавычках).
* `pwd` — вывод полного пути текущей рабочей директории VFS.
* `source <файл>` — построчное выполнение команд из файла скрипта с немедленной остановкой и выводом номера строки при возникновении первой ошибки.
* `reinit` / `vfs-init` — сброс виртуальной файловой системы в исходное состояние.
* `exit` — завершение работы эмулятора и закрытие окна терминала.

### Архитектура программных модулей (`src/emulator.py`)
* `VFS` — управление структурой каталогов и файлов в оперативной памяти, нормализация путей через `posixpath` и чтение ZIP-архивов.
* `ShellEngine` — разбор введённых строк с помощью `shlex.split` и диспетчеризация команд независимо от графического интерфейса.
* `ShellGUI` — реализация окна терминала и обработки пользовательского ввода на базе `tkinter`.

## 3. Описание команд для сборки проекта и запуска тестов
Проект реализован на языке Python 3 с использованием только стандартной библиотеки — установка сторонних пакетов не требуется.

```bash
# Запуск пакета модульных тестов
python -m unittest discover -s tests

# Запуск единого скрипта проверки (тесты + запуск эмулятора)
./run.sh
```
*(В среде Windows PowerShell скрипт запускается командой `bash run.sh`).*

## 4. Примеры использования

```bash
# Базовый запуск эмулятора с настройками по умолчанию
python src/emulator.py

# Запуск с автоматическим прогоном стартового скрипта (успешный сценарий)
python src/emulator.py --script tests/script_ok.txt

# Проверка аварийной остановки при ошибке в стартовом скрипте
python src/emulator.py --script tests/script_error.txt

# Запуск с подключением пользовательского архива VFS и своего приглашения
python src/emulator.py --vfs vfs_samples/archive.zip --prompt "student$ "
```
